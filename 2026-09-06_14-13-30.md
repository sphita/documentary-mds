# Update: Dynamic Datasets Hub Integration
**Date**: 2026-09-06

## Changes Made
1. **New `/datasets` Page Created**: Built `datasets.html` following the sitewide visual language (monochrome grid, offset orbs, glassmorphic UI).
2. **Dynamic API Integration**: Integrated a completely serverless, automated data pipeline into `script.js` using the `fetch()` API. It now automatically pulls live datasets, download counts, and like counts from the Hugging Face REST API (`https://huggingface.co/api/datasets?author=sphita`). This permanently eliminates the need to manually update dataset sizes, stats, or links in the code.

4. **Sitewide Navigation Updates**: Added the `Datasets` link to the main navigation across `index.html` and `about.html`, ensuring seamless routing.
