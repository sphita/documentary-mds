# Update: Zero-Database Markdown Blogging System
**Date**: 2026-09-06

## Changes Made
1. **Created Hub & Post Pages**: 
   - `blogs.html`: Serves as the central blog hub, rendering dynamic preview cards for all available posts.
   - `post.html`: A dynamic reading template that parses URL parameters to display a specific post.
2. **Markdown Injection (`script.js`)**: 
   - Integrated `marked.js` via CDN to instantly compile Markdown into HTML on the client-side.
   - Posts are simply raw `.md` files stored in a new `/posts/` directory. No Jekyll compilation or local databases required.
3. **Index Routing (`blog-index.js`)**: 
   - Created a lightweight JSON array to serve as the "database router". To publish a new blog, developers only need to drop a `.md` file into the folder and add its metadata to this array.
4. **Prose Styling**: 
   - Added specific CSS (`.prose`) to render Markdown beautifully, complete with syntax-highlighted code blocks (`<pre><code>`), blockquotes, custom headings, and readable line heights.
