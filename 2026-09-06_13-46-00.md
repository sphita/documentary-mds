# Update: Navigation & Footer SVG Integration with Animations
**Date**: 2026-09-06

## Changes Made
1. **SVG Integration**: Modified the global navigation and footer across `index.html` and `about.html`. Replaced the plain text "Datasets" link with the official `hf-logo.svg` and the plain text "GitHub" link with `icons8-github.svg`.
