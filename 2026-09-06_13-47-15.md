# Update: Dynamic Footer Year Logic
**Date**: 2026-09-06

## Changes Made
1. **HTML Updates**: Modified `index.html` and `about.html` footer elements to include `2026` inside the `<span id="year">2026</span>` tags as a hardcoded fallback.
2. **JavaScript Updates**: Modified `script.js` to implement conditional logic for the copyright year. 
   - If the user's browser year is currently `2026`, it simply renders `2026`.
   - Once the year changes to `2027` or beyond, it will dynamically render `2026 - {currentYear}`.
